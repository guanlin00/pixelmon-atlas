# Pixelmon Atlas — Beta v0.3

可直接在瀏覽器開啟 `index.html`。需將 `index.html`、`verified-data.js`、`app.js` 和 `style.css` 保持在同一個資料夾。

## v0.3 更新
- 移除重複的「套用搜尋」按鈕，保留即時篩選。
- 篩選欄底部改為「選擇條件後，搜尋結果會自動更新」提示。
- 保留重設按鈕、搜尋結果數量、已選條件標籤及既有官方資料。

## v0.2 更新
- 道具詳細頁移除多餘的「取得方式與反查」頁籤，重新設計標題、取得方式、掉落表和合成用途。
- 匯入官方 Pixelmon Wiki「Ender Pearl」頁面列出的 47 筆掉落寶可夢、機率與數量；點擊可進入圖鑑詳細頁。
- 凱西與勇基拉的森林類別（Forests）及不限時間生成資料依各自 Wiki 條目整理；頁面中用「森林」選項作為簡化分類，並非已匯入完整的精確生態域清單。
- 保留部分舊版展示用生成規則，清楚標明尚待驗證；不把這些規則當作官方事實。
- 已核對的道具／掉落資料於頁面提供官方來源連結。
